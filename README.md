# Front-End Development with HTML, CSS, JavaScript & TypeScript
A collection of hands-on practice programs and mini exercises covering front-end web development using HTML, CSS, JavaScript, and TypeScript. This repository demonstrates fundamental web development concepts, DOM manipulation, events, arrays, objects, functions, AJAX (XHR), and TypeScript basics.

## 📌 Overview

This repository was created to strengthen front-end development skills through practical coding exercises and examples. It covers core web technologies, JavaScript programming concepts, and TypeScript fundamentals.
